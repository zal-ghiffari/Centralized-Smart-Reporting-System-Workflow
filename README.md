## Centralized Smart Reporting System Workflow
### N8N Workflow Installation and Configuration
Instalasi n8n dapat dilakukan dengan mengikuti petunjuk resmi dari website n8n <a href = "https://docs.n8n.io/hosting/"><img src="https://n8n.io/guidelines/logo-dark.svg"/></a> (sesuaikan dengan sistem operasi). Setelah berhasil, download json pada repository berikut. kemudian import pada workflow n8n. Setelah itu mungkin anda perlu melakukan konfigurasi pada (semua dokumentasi sudah ada pada website 8n8):
1. Kredensial Bot Telegram
2. Kredensial Database
3. Koneksi Request ke API Service
4. Konfigurasi SMTP (SMTP2GO) server dan IMAP
5. Konfigurasi Webhook untuk Form
